# Jecon 利用ガイド

Jecon は Bukkit/Spigot 用の経済プラグインで、Vault / VaultUnlocked から利用できる残高管理基盤を提供する。
プレイヤー同士の送金、非プレイヤー口座（システム口座・法人口座など）、MySQL/SQLite バックエンド、Modifier パイプラインなどを備える。

このディレクトリには、対象読者別のガイドを配置している。

## 目次

- **[利用者向け（基本機能）](./user-basic.md)**
  - `/money`（残高確認）、`/money pay`（送金）など、日常的に使う機能。
  - すべてのプレイヤーがデフォルトで使える範囲。
- **[利用者向け（発展機能）](./user-advanced.md)**
  - `/money top` などランキング系や、通貨表示の読み方、送金失敗時の挙動、他プラグイン（Shop / Job など）との関係。
  - 通常利用ではあまり触らない挙動をまとめる。
- **[管理者向け](./admin.md)**
  - 設定ファイル、パーミッション、口座管理、非プレイヤー口座 (`/jecon account ...`)、データベース、Vault 連携、トラブルシューティング。

## 前提

- 対応 Minecraft API バージョン: 1.21 以上 (`plugin.yml` の `api-version: 1.21`)。
- プラグインコマンドの入口は `/jecon` および `/money`（両方とも同じコマンド）。
- 残高は内部的に「セント（値 × 100 の整数）」として保持しており、通貨としては 2 桁の小数点精度を持つ。
