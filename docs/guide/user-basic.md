# 利用者向けガイド（基本機能）

このページでは、Jecon が導入されたサーバーで **プレイヤーとして日常的に使う機能** をまとめる。
より踏み込んだ機能（ランキング、通貨表示のフォーマットなど）は [利用者向け（発展機能）](./user-advanced.md) を参照。

## 前提

- コマンドは `/money` と `/jecon` のどちらでも同じ動作をする。以降は短い `/money` で表記する。
- サーバーに初参加すると、通常は自動的にあなた用の口座が作られ、初期残高が入る（初期残高はサーバー設定による）。
- 残高は 2 桁の小数点精度（例: `123.45`）で保持される。

## 残高を確認する — `/money`

自分の現在の残高を表示する。

```
/money
```

`/money show` と書いても同じ挙動になる。

出力例（英語ロケール、デフォルトフォーマット）:

```
f0reach balance: 100 dollars 0 cents
```

出力の見え方はサーバー側の設定（[管理者向けガイド — フォーマット設定](./admin.md#format-通貨表示のカスタマイズ)）に依存するので、
サーバーによっては `$ 100.00` や `100円` のように表示されることもある。

### 必要な権限

- `jecon.show`（デフォルトで全プレイヤーに付与）

## プレイヤー間で送金する — `/money pay`

他のプレイヤーへ金額を送る。

```
/money pay <player> <amount>
```

例:

```
/money pay Steve 500
```

送金が成功すると、送信側と受信側の両方にメッセージが届く。

- 送信側: `Sent a <amount> to <name>.`
- 受信側（オンライン時のみ）: `Received a <amount> from <name>.`

### 制約と失敗パターン

以下のケースでは送金は行われず、エラーメッセージが表示される。

- **金額不足**: 自分の残高が `<amount>` に満たない → `The balance of the account is not enough.`
- **相手が未登録**: `<player>` に口座が存在しない → `Account not found: <name>`
- **自分自身への送金**: `<player>` として自分を指定した場合 → `Invalid argument: <name>`
- **プレイヤー以外からの実行**: コンソールや、プレイヤーとして実行していない環境からは実行できない。

### 必要な権限

- `jecon.pay`（デフォルトで全プレイヤーに付与）

### 補足

- `<amount>` には 0 以上の数値を指定する（`0` は許可されるが実質的に意味はない）。
- 小数点入力は 2 桁までを想定（内部で丸められる）。
- 「送金する」処理は、[振替（Transfer）API](../spec/03-transfer-api.md) を通り、
  ログや Modifier パイプライン（税・上限など）に接続される。
  サーバー側で税や制限が設定されている場合は、名目上の金額と実際に相手に届く金額が違うことがある（[利用者向け（発展機能）](./user-advanced.md#送金は必ずしも「そのまま」届くわけではない)）。

## ヘルプを見る — `/money help`

利用可能なサブコマンドの簡易ヘルプを表示する。

```
/money help
```

権限に応じて表示されるコマンドが変わる（実行できないコマンドは基本的に見えない）。

## 使わないと思うが覚えておくと便利なコマンド

これらも「基本機能」の一部として付与されている。

- `/money show`
  - 引数なしの `/money` と同じで、自分の残高を表示する。
- タブ補完
  - `/money pay ` まで打った時点で TAB を押すと、送金先候補のプレイヤー名がサジェストされる。

## トラブルシューティング（利用者側）

- **`You don't have permission!!` と出る**:
  サーバー管理者が権限を絞っている可能性がある。基本のふたつ（`jecon.show`, `jecon.pay`）はデフォルトで全員に付いているが、
  権限プラグインで明示的に外されていることもある。管理者に確認する。
- **`Account not found: <自分の名前>` と出る**:
  何らかの理由でまだ口座が作られていない状態。ログインし直すか、管理者に `/money create <あなた>` を実行してもらう。
- **表示される通貨単位が変**:
  サーバー側の `config.yml → format` セクションのカスタマイズによる。仕様上の異常ではない。
